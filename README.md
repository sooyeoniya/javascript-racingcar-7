# javascript-racingcar-precourse

**프리코스 최종 코딩 테스트 연습을 위한 브랜치입니다.**

**구현 기간:** `24.11.16` ~ 

## ✅ 기능 목록

### 입력

  - [x] 경주할 자동차 이름 입력
    - 쉼표 기준으로 이름 분리
    - 앞뒤 공백 제거
  
  - [x] 시도할 횟수 입력
    - 최대 시도 횟수 제한

### 기능

  - [x] 각 차수별 경주 게임 실행
  - [x] 각 자동차별 `0`에서 `9`사이의 무작위 값 생성
  - [x] 무작위 값이 `4`이상인 경우만 전진

### 출력

  - [ ] 시도 횟수에 따라 매 차수별 누적 결과 출력
  - [x] 최종 우승자 출력
    - 동점일 경우 동점자 모두 출력

### 예외 처리

  - [x] 경주할 자동차 이름
    - [x] 입력 값이 빈 경우
    - [x] 중복된 이름이 있는지
    - [x] 이름이 `5`자 이하인지
    - [x] 이름 중간에 공백이 있는지

  - [x] 시도할 횟수
    - [x] 숫자인지
    - [x] 정수인지
    - [x] 0보다 크고 최대 시도 횟수보다 작은지
